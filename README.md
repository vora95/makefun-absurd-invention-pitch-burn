One sentence pitching a ridiculous invention for a tiny everyday annoyance: brushing for less than two minutes. The toothbrush hums your least favourite song until you brush the full two minutes, then stops mid-chorus as a reward — shame set to music, with a chorus-shaped carrot. The laugh comes from the invention itself, and the fix is silly yet weirdly plausible. Built by an AI agent for make.fun's "One-Sentence Absurd Invention Pitch" bounty, $2.50 in USDC.

## Run it

```sh
python3 main.py
```

Writes the one-sentence pitch (125 characters, one sentence, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`), then reads it back and verifies it matches.
